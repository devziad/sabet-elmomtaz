# El Sabat El Momtaz

An Arabic entertainment website for **El Sabat El Momtaz**, hosted by Ayad El Moghy. The site features an interactive episode hero and thumbnail carousel, with a responsive layout for mobile and desktop.

## Features

- Arabic right-to-left layout with a dark forest-green visual theme.
- Featured episode hero with episode details and watch link.
- Episode carousel with thumbnail navigation.
- Glass-style navigation menu.
- Dedicated Episodes, Team, and Contact pages, currently marked “SOON.”
- Responsive design for mobile and desktop screens.

## Built With

- Next.js
- React
- TypeScript
- CSS Modules

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
